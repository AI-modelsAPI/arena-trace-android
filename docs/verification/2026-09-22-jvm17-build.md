# 构建修复验证报告 — JVM 目标统一为 17

- 日期：2026-09-22（Asia/Shanghai）
- 分支：`fix/jvm-target-17`，基线 `main@09201f7556bb9c649991b208cfc5170d4c4a273e`
- 改动：仅 `app/build.gradle.kts`，新增 11 行（`compileOptions` + `kotlin.compilerOptions.jvmTarget`），未改依赖、行为、包名、版本或 SDK。

## 根因

`compileDebugKotlin` 失败：`Inconsistent JVM-target compatibility detected for tasks
'compileDebugJavaWithJavac' (1.8) and 'compileDebugKotlin' (17)`。AGP 默认 Java 目标为 1.8，
Kotlin 2.0 默认按工具链取 17，两者不一致导致 Kotlin 编译任务在校验阶段中止。

## 修复

在 `android {}` 内显式声明 `sourceCompatibility = targetCompatibility = JavaVersion.VERSION_17`，
并用 `kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_17) } }` 对齐 Kotlin 目标。
